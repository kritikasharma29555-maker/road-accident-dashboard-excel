# Road Accident Dashboard (Excel)

##  Project Overview
An interactive and dynamic Excel dashboard designed to analyze road accident data, identifying key casualty trends, environmental factors, and vehicle distribution to help improve road safety awareness.



##  Key Insights & Metrics
* **Total Casualties:** 417,883
  * **Slight Casualties:** 84.10% (351,436)
  * **Serious Casualties:** 1.19% (59,312)
  * **Fatal Casualties:** 1.71% (7,135)
* **Casualties by Vehicle Type:** Cars account for the majority of casualties at **79.0%** (333,485), followed by vans/lorries, bicycles, and buses.
* **Road & Environmental Analysis:**
  * **Road Type:** Single carriageways recorded the highest number of casualties (309,698).
  * **Road Surface:** Analysis across dry, wet, and snow/ice conditions.
  * **Light Conditions:** Breakdown comparing accidents occurring in daylight versus dark conditions.
* **Year-over-Year Comparison:** Tracks monthly trend lines comparing Current Year (CY) vs. Previous Year (PY) casualties.



##  Tools & Excel Techniques Used
* **Data Visualization:** Custom Doughnut Charts, Bar Charts, Line Charts, Treemaps, and KPI Cards.
* **Interactivity:** Dynamic Slicers and Timeline Filters for seamless data exploration by area (Urban vs. Rural) and date ranges.
* **Formulas & Functions:** Data cleaning and aggregation using conditional summary functions (`SUMIFS`, `COUNTIFS`) and lookup functions.
